# 라스트로얄 (LAST ROYAL)

라스트오리진 에셋으로 만든 HTML 실시간 카드 대전 (클래시 로얄 스타일). 렌더링은 three.js(r128, 로컬 포함) + 블룸 후처리.

## 실행

`run_server.bat` 더블클릭, 또는:

```
python tools/serve.py 8766
```

→ http://localhost:8766 (`index.html`을 바로 열어도 동작하지만 서버가 로딩·사운드에 유리합니다)

## 규칙

- **진영**: 오르카(바이오로이드) 또는 철충(기계 군단)을 고르면 상대는 반대 진영 AI 지휘관입니다. AI 덱은 매 판 무작위로 구성됩니다.
- **전장**: 18×32칸. 가운데 에너지 협곡은 다리 두 곳으로만 건너며, 비행 유닛과 *머큐리 / 둠 이터*는 협곡을 넘습니다.
- **타워**: 각 진영 프린세스 타워 2 + 킹 타워 1. 타워 위의 캐릭터(오르카: 님프·콘스탄챠 / 철충: 엑스큐셔너·철의 왕자)가 직접 공격합니다.
  킹 타워는 피해를 입거나 프린세스 타워가 무너지면 가동됩니다.
- **에너지**: 시작 5, 최대 10, 2.8초에 1. 남은 1분은 2배, 연장전은 3배. *에너지 폭주* 모드는 처음부터 2배.
- **덱**: 8장. 손패 4장 + NEXT. 사용한 카드는 덱 맨 뒤로 돌아갑니다.
- **배치**: 아군 진영(점선 아래)에만. 적 프린세스 타워를 부수면 그 라인의 적 진영 앞쪽까지 배치 가능. 주문은 어디든.
- **챔피언(SS 등급)**: 전장에 있으면 오른쪽 아래 스킬 버튼이 나타납니다. 에너지를 써서 고유 스킬 발동(광역 기절, 포격, 레이저, 낙뢰, 돌진, 소환, 방어막, 가속).
- **승리**: 3분 뒤 크라운이 많은 쪽. 같으면 1분 연장전(먼저 타워를 부수면 승리), 그래도 같으면 가장 약한 타워의 남은 체력 비율로 판정.
  킹 타워를 부수면 즉시 3크라운 승리.
- **조작**: 카드를 전장으로 드래그, 또는 카드를 누른 뒤 전장을 누름. 키보드 `1~4` 카드 선택, `Q` 챔피언 스킬, `Esc` 취소/일시정지. 감정 표현 버튼.

## 성장

- **트로피 로드 / 아레나 5단계**: 훈련 구역 → 폐허 도시(300) → 철충 둥지(800) → 오르카 호 갑판(1500) → 최종 결전(2500).
  아레나마다 전장 색이 바뀌고, 새 카드가 해금되고, 상대 카드 레벨이 오릅니다. 도달한 아레나 아래로는 떨어지지 않습니다.
- **보급 상자**: 승리하면 상자(일반/정예/특급)를 얻어 4칸 슬롯에 보관, 하나씩 실시간으로 해제(30초~5분)해 열면 부품과 카드 사본.
  슬롯이 가득 차면 카드를 바로 받습니다. 카드 사본 + 부품으로 카드 강화(레벨당 체력·공격력 +10%, 최대 Lv.9).
- **타워 레벨**: 내 타워는 덱의 평균 카드 레벨, 상대 타워는 상대 레벨을 따라 강해집니다. 상대 레벨은 아레나와 내 덱 레벨에 맞춰집니다.
- **AI 지휘관**: 진영마다 4명, 성향(돌격형·수비형·공성형·균형형)에 따라 공세 시점, 라인 분산, 역습, 덱 구성이 다릅니다.
- **모드**: 일반전 / 에너지 폭주(처음부터 2배) / 무작위 덱(양측 모두 해금 카드로 만든 무작위 덱) / 오늘의 작전(날마다 바뀌는 규칙: 거울 작전, 영웅의 날, 전격전, 거인의 전장).
- **AI 덱**: 무작위로 짜되 내 덱에 맞서도록 보강합니다(공중 대응, 건물 유인, 무리 대응).
- **트로피 로드**: 트로피 100마다 부품, 500마다 상자 보상(타이틀에서 받기).
- **작전 임무**: 3개씩 주어지는 목표(승리, 크라운, 스킬 사용 등)를 달성하면 부품 보상.
- 진행은 브라우저(localStorage)에 저장됩니다. 설정에서 초기화할 수 있습니다.

### 캐릭터와 이펙트

캐릭터는 오르카 랜덤 디펜스(`5_LAO_Defence`)와 같은 방식입니다: Unity 프리팹과 `.anim` 클립을 변환한 `js/sd/<id>.js` 리그를
`js/sd.js`가 재구성·재생합니다(Puppet2D IK 포함, 캐릭터 하나 = 아틀라스 1장 + 메쉬 1개).

- 공격은 원작 공격 클립의 발사 이벤트 구간을 반복 재생하고, 이벤트 프레임마다 원작 총구 위치(`fire` 체인 → 무기 끝)에서
  원작 투사체(`FX_META`의 궤적 LINE/CURVE/HOWITZER)를 쏘고 원작 피격 이펙트를 터뜨립니다. 첫 발이 피해를 주고 나머지는 연출입니다.
- 원작 이펙트가 없는 공격(철충 등)은 공격 유형별로 어울리는 원작 피격 이펙트를 빌려 씁니다.
- 챔피언 스킬은 원작 스킬 클립을 재생합니다.

## 품질·안정성

- 고정 60Hz 시뮬레이션, 프레임 지연 시 백로그 버림. 충돌은 2칸 공간 격자, 진영별 유닛 목록.
- 캐릭터 리그: 시뮬레이션은 클립 시간만 진행하고 포즈 계산은 화면 프레임당 1회(유닛 100기 이상에서도 프레임당 약 8ms). 한 프레임 예외는 기록 후 전투 계속.
- 프레임 작업 시간을 측정해 그래픽 품질(해상도·블룸·파티클 수)을 자동으로 낮춤(설정에서 고정 가능).
- 캐릭터·이펙트 인스턴스 풀링, 전투 종료마다 풀 정리. WebGL 컨텍스트 유실 시 정지 후 복구.
- 리그 로드 실패 시 재시도, 그래도 실패하면 보이지 않는 대체 유닛으로 계속. 이펙트 로드 실패는 파티클로 대체.

## 테스트

`index.html?smoke=1&mute=1` — 양 진영 × 3개 모드 × 5개 아레나를 봇으로 끝까지 플레이하고 상자 즉시 해제·개봉까지 검사(오류 수 표시, 진행 저장은 원래대로 복구).
콘솔에서 `GAME._run(초)` — 전투를 즉시 진행(백그라운드 탭에서도), `GAME._playCard(side, 손패번호, x, z)` — 카드 사용,
`GAME.info` — GPU 메모리/씬 객체 수. `?mute=1` — 소리 끄기(설정은 유지).
