# 클래시로얄 대응표 (10레벨 기준)

기준 수치는 클래시로얄 게임 데이터 표(RoyaleAPI cr-api-data, 2023-10-18 라이브 데이터)의 10레벨 값입니다. `python tools/cr_reference.py`로 `tools/cr_reference.json`을 만들고 `node tools/balance_audit.js`로 차이를 점검합니다. 철충 카드는 공격이 1.4배 느리고 그만큼 강하며, 초당 피해는 같습니다.
