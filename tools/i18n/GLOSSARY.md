# Translation glossary — "라스트 워" (LAST WAR), a real-time card battler made with Last Origin characters

Keys are the Korean source text. Keep `{0}`, `{1}` … placeholders exactly (they are numbers, names or other
translated text filled in at run time); keep symbols such as ★ ✓ · / + x - ( ) and numbers as they are; never add HTML.
Short UI labels must stay short (buttons on a 375 px phone screen). Use the Last Origin official name of a character
when you know it (e.g. 브라우니 Brownie, 레프리콘 Leprechaun, 임펫 Impet, 레이븐 Raven, 하르페 Harpe, 엠프레스 Empress,
발키리 Valkyrie, 그렘린 Gremlin, 라비아타 Labiata, 티타니아 Titania, 아자젤 Azazel, 렘파리온 Rampart); otherwise
transliterate. Enemy machines (철충) keep their Last Origin names (나이트 칙 Night Chick, 레기온 Legion, 퍼프헤드 Puffhead…).
